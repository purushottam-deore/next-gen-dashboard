# Next Gen Learning Dashboard

## Tech Stack
- Next.js App Router
- Tailwind CSS
- Supabase
- Framer Motion
- Lucide React

## Architecture
- Server Components used for fetching Supabase data
- Client Components used for animations and interactions
- Suspense loading via loading.tsx
- Responsive Bento Grid Layout

## Features
- Animated Bento Grid
- Dynamic Course Cards
- Animated Progress Bars
- Sidebar Layout Animations
- Skeleton Loading States
- Responsive Design

## Run Locally

npm install
npm run dev
